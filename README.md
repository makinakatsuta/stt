# サウンドテーブルテニス（STT）

視覚障害者向け競技「サウンドテーブルテニス（STT）」を、音と声を頼りに体験できるブラウザゲームです。

## すぐに遊ぶ

1. `stt.exe` を起動します。
2. ブラウザで <http://localhost:8080> を開きます。
3. 「音声を有効化」→「CPU対戦」→難易度の順に選びます。

ソースコードから起動する場合は、次のコマンドを実行してください。

```bash
go run main_server.go
```

## 遊び方

- 主審の「プレー」を聞いてサーブの準備をします。
- サーバーの「いきます」に対して、レシーバーが「はい」と返事します。
- サーブ後は、ボールの転がり音を聞いてラケットを合わせ、返球します。
- サーブを打った後もラケットを左右に移動でき、自分に戻ってきたボールを返球できます。
- ラリーが終わると、主審が結果とスコアを読み上げます。

## 操作方法

| 操作 | PC | スマートフォン |
|---|---|---|
| ラケット移動 | `←` `→` | 端末を水平にして左右へ傾ける |
| サーブ・返球・決定 | `Space` | 画面タップ（VoiceOver / TalkBackはダブルタップ） |
| 戻る・終了 | `Escape` | 画面の案内に従う |

スマートフォンでセンサーを使わない場合は、Bluetoothキーボードも利用できます。

## ルール

- 1ゲーム11点先取、10対10以降は2点差がつくまで続きます。
- 通常は2ポイントごと、10対10以降は1ポイントごとにサービス権が交替します。
- 3ゲーム中2ゲームを取ると試合に勝利します。
- サービス、ネット下通過、セーフ・アウト、ボール停止など、STTの基本ルールに対応しています。

現在プレイできるのはCPU対戦です。オンライン対戦は一時停止中です。

## 音について

ラリー中は `SMASH1.m4a` が再生されます。ボールの音の大きさや音色、左右の聞こえ方が距離や位置に合わせて変化します。最初に「音声を有効化」を押してください。

音量を上げすぎず、周囲の安全を確認してプレイしてください。スマートフォンは落とさないように持ってください。
