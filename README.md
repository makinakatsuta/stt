# サウンドテーブルテニス (STT) オンライン

サウンドテーブルテニス (STT) は、視覚障害者のために考案された卓球競技です。
このプロジェクトは、STTの公式ルールに準拠し、**視覚障害者（モバイル/PCのスクリーンリーダー利用者）も健常者も共に同じ条件で対戦できる**ことをコンセプトとした、GoバックエンドおよびWeb Audio API搭載のリアルタイムブラウザゲームです。

---

## 🌟 主な特徴

1. **Web Audio API による3D立体音響システム**
   * Web Audio API の `PannerNode`（HRTF）により、ボールの左右だけでなく、相手コート奥から自陣守備ラインへ近づく奥行きも立体的に表現します。
   * 金属球が4個入ったSTT公式ボール特有の「シャラシャラ」という転がり音をオシレーターとノイズを用いてリアルタイムに合成します。
   * ボールが手前へ近づくほど、残り距離に応じて金属球の刻み周期を速くし、到達までの時間間隔を耳で把握できるようにしています。
   * 木製ラケットで打球した時の「コン」、フレームに当たった時の「カツ」、ネットに当たった時の「ポス」など、素材感のある衝突音を再現しています。
   * **チャージサーブ音響**: スペースキー長押し中にピッチが上昇するチャージ音を合成。長押し時間（最大1.5秒）に応じてサーブ速度が変化します。
   * **ミス方向ガイド音**: 打ち返しミス時に「左/右/中央を通りました」と方向付きのステレオ音響でフィードバック。スクリーンリーダー利用者も次のラリーに活かせます。
   * **ボール停止位置音**: ボールが停止した際に、停止X座標にパンニングした「コトン」音を再生。「どこで止まったか」が音で把握できます。
   * **音量ダイナミクスの対数スケール化**: ボール転がり音の音量を対数スケールで計算し、低速域の微妙な音量変化をより豊かに表現。

2. **完全アクセシビリティ（PC・スマホ両対応、スクリーンリーダー＆音声ガイド）**
   * Web Speech API (`SpeechSynthesis`) による自動音声案内（実況）を搭載。審判のコールや、サーブ前の掛け合い（「いきます」「はい」）をすべて音声で実況します。
   * スクリーンリーダー（iOSのVoiceOver、AndroidのTalkBack）の操作を妨げないセマンティックなHTML構造とARIA属性設計。
   * パソコンではキーボードの最小限のキー（左右矢印とスペースキー）、スマートフォンでは端末を水平に持って体を左右に動かす加速度センサー操作と画面タップでプレイできます。
   * **音声速度設定**: ウェルカム画面のスライダーで読み上げ速度を0.5〜2.0倍に調整可能。設定はlocalStorageに保存され次回起動時に復元されます。スクリーンリーダー熟練者は速い読み上げに設定できます。

3. **CPU対戦を中心としたクロスプラットフォーム対応**
   * PC・スマートフォンのブラウザで、同じ音響・アクセシビリティ機能を利用してCPU対戦をプレイできます。
   * オンライン対戦は現在一時停止中です。メニューで選択すると 500 Internal Error の案内が表示されます。

4. **ゲームプレイ体験の向上**
   * **CPU戦のサーブ交代**: Normal/Hard難易度では2ポイントごとにサーブ権が交代。プレイヤーがサーブする場面でSTT本来の心理戦（「いきます/はい」）を体験できます。Easy難易度はCPUサーブ固定のまま（ラリー練習重視）。
   * **チャージサーブ**: `STATE_SERVE_WAITING` 中にスペースキーを長押しすると、長押し時間（最大1.5秒）に応じてサーブ速度（vy: 4.5〜8.0）が変化します。
   * **打ち返し判定の難易度別調整**: 判定幅をEasy=50px、Normal=30px、Hard=20pxに設定し、難易度に合った打ち返しやすさを実現。
   * **インターバルスキップ**: 得点後4秒の待機中に、スペースキーまたはタップで即座に次のラリーへ進めます。
   * **試合結果画面**: 試合終了後に勝者・最終スコアを表示し、「もう一度プレイ」「メニューに戻る」の選択ができます（従来の6秒自動退出を廃止）。
   * **設定の永続化**: 難易度、加速度センサー操作のON/OFF、サーバーアドレス、音声速度をlocalStorageに保存し、次回起動時に自動復元します。

5. **プレミアムな視覚デザイン（健常者向け）**
   * ダークモードを基調としたネオン・サイバーパンク調の美しいグラフィック。スマートフォンの表示にも完全対応したレスポンシブ設計。
   * ボールの軌跡や、衝突時にコート上に広がる「音の波紋（パルス）」を可視化。音の動きを視覚的にも体感できます。
   * **STT公式規格・寸法ガイドの可視化**: 卓球台の正確な寸法（長さ274cm、幅152.5cm、サイドフレーム60cm、ネット高さ15.25cm、ネット下の隙間4.2cm）を、ゲーム画面内のネオン調寸法線と、右側のリアルタイム寸法規格サイドパネル（SVG図解付き）で視覚的に表現しました。見える人にとってもSTTの独特なルールスケールが一目で理解できます。

## 🎮 遊び方・操作方法

使用するデバイスやアクセシビリティ設定に合わせて、最適な操作方法を選択できます。

### 1. パソコンでの操作（標準キーボード）
* **左矢印キー (`ArrowLeft`)**: ラケットを左に移動
* **右矢印キー (`ArrowRight`)**: ラケットを右に移動
* **スペースキー (`Space`)**: アクション（サーブの準備、相手への返答、メニュー決定、ラリー中の打ち返し）
* **エスケープキー (`Escape`)**: ゲームの一時停止 / メニューに戻る

### 2. スマートフォンでの操作（加速度センサー ＋ 画面タップ）
スマホ単体でプレイする場合、タッチドラッグ操作がスクリーンリーダーにブロックされるのを防ぐため、以下の操作になります。
* **ラケットの移動（体移動操作 ＋ 足音ガイド）**:
  * スマートフォンを**水平に持ち、体を左右に動かす**と、横方向の加速度に応じてラケットが左右に移動します。端末を傾けて操作する必要はありません。
  * 小さな手ブレはデッドゾーン（不感帯）で無視されます。移動の加速度が大きいほどラケットの移動速度も速くなる比例操作です。
  * **ラケット移動時のステレオ音響**: ラケットを動かすと、その位置に応じたステレオパンニング（左右の定位）と微妙な音色変化（中央に近づくほどクリアになる）の足音が鳴ります。これにより、スピーカーのちょうど真ん中（パン値0）でボールを待ち構えやすくなりました。
  * iOS では、開始時に表示される加速度センサー利用許可を承認してください。
  * プレイ中に画面下部の**「ラケット位置をリセット（中央に戻す）」**ボタンをタップ（またはダブルタップ）すると、ラケットを中央位置へ戻せます。
* **アクション（決定/サーブ/打ち返し）**:
  * **画面全体のどこでもタップ**（VoiceOverやTalkBackなどの**スクリーンリーダー起動時は画面の任意の場所をダブルタップ**）することで、スペースキーと同じアクションが発生します。
* **設定の切り替え**:
  * 開始時のウェルカム画面で「体を左右に動かしてラケットを操作する（加速度センサー）」のチェックを外すと、スマホに接続した外付けのBluetooth物理キーボード（パソコンと同じ操作）で遊べます。加速度センサーに対応していない端末でも同様です。

### STT公式ルールに基づくプレイフロー
1. **主審の「プレー」宣告**でラリーの準備が始まります。
2. **サーバー**: スペースキーまたは画面タップ（ダブルタップ）を押してボールを静止させ、準備ができたら「いきます」と発声します。（10秒以内）
3. **レシーバー**: サーバーの「いきます」に対してキー/タップで「はい」と返答します。（5秒以内）
4. **サーバー**: 返答から5秒以内にキー/タップでサーブを打ちます。（5秒以内）
5. **ラリー開始**: ボールがネットの下（テーブル面上4.2cmの隙間）を通って転がってくるので、音（左右の定位や音量）を頼りにラケットを動かしてタイミングよく打ち返します。
6. **得点判定**: ボールが相手の守備コート内で「停止」するか、エンドフレーム（奥の壁）の内側に当たって「セーフ」になれば得点です。フレームを越えて飛び出たり（アウト）、ネットに引っかかったり、ラケット以外の場所に当たると相手の得点になります。

## 🚀 起動方法

### 方法1：実行ファイルから起動（推奨・最も簡単）
1. プロジェクトルートにある `stt.exe` をダブルクリックして実行します。
2. サーバーが起動し、自動的にデフォルトのブラウザで `http://localhost:8080` が開きます。

### 方法2：Goソースコードから起動（開発者向け）
1. ターミナルでプロジェクトディレクトリに移動します。
   ```bash
   cd stt
   ```
2. 以下のコマンドでサーバーを起動します。
   ```bash
   go run main_server.go
   ```
3. サーバーが起動すると、自動的にブラウザで `http://localhost:8080` が開きます。
