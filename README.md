# サウンドテーブルテニス（STT）

現在のリリース：**v3.31.27**（2026-09-24）

各バージョンの追加機能・改善・修正内容は、[リリースノート](release-notes.txt)をご覧ください。

音を聞いてボールの位置を判断し、自分でラケットを左右に動かして返球するブラウザゲームです。音声案内、スクリーンリーダー向けの通知、配色・文字サイズの設定を備えています。ヘッドホンまたはイヤホンでのプレイをおすすめします。

現在遊べるのは **CPU対戦** です。オンライン対戦は一時停止中です。

## はじめて遊ぶ

### Windowsで起動する

1. [v3.31.27のリリースページ](https://github.com/makinakatsuta/stt/releases/tag/v3.31.27)から `stt.exe` をダウンロードします。
2. `stt.exe` を起動します。必要な画面・音源・WASMは実行ファイルに含まれています。
3. ブラウザで `http://localhost:8080` を開きます。別のURLが表示された場合は、起動時に表示されたURLを使ってください。
4. 「オーディオを有効にして開始する」を押し、「CPU対戦」から難易度を選びます。

音が聞こえるよう、ヘッドホンまたはイヤホンの使用をおすすめします。

### どんなゲーム？

音を聞いてボールの位置を判断し、ラケットを左右に動かして返球するブラウザゲームです。移動も返球も自分で操作します。音声案内、スクリーンリーダー向けの通知、配色・文字サイズの設定があります。

### 読み上げを使う場合

起動画面または中断メニューの「読み上げ方式」で、ゲーム内蔵音声（初期設定）かスクリーンリーダーを選べます。設定は保存されます。内蔵音声が使えない場合はスクリーンリーダー向け通知に切り替わります。球音・打球音はどちらの方式でも再生されます。

プレイ画面の「サーブ・返球」ボタンは、スクリーンリーダーから実行できます。キーボードでは Enter または Space、タッチ画面ではタップで操作できます。サーブの準備から返球、得点後の待ち時間のスキップまで使えます。このボタンでサーブするときは長押し不要です。従来のコート上の操作やSpaceによるチャージ操作も使えます。

全盲の利用者によるWindowsのFirefox・Chrome・Edge、およびAndroidのChromeでのプレイ報告があります（2026-09-24）。v3.31.27では音声通知などを修正し、自動テストで確認しました。修正後の実機読み上げ確認は未実施です。

## 3つの難易度

| 難易度 | こんな遊び方ができます |
|---|---|
| **簡単（Easy）** | 球がゆっくりで、返球しやすい練習向けの難易度です。ラリーが長くなりすぎないよう、CPUが一定回数でミスをします。 |
| **ノーマル（Normal）** | 球速やコースに変化がある、標準の難易度です。CPUは状況に応じてコースや球速を変えます。 |
| **ハード（Hard）** | CPUの移動が速く、プレイヤーの返球判定も厳しくなります。CPUは速球と遅球を打ち分けます。 |

どの難易度でも、ラケットの移動と返球はプレイヤーが操作します。自動追尾やプレイヤー側の球速選択はありません。得点後は判定・得点者・スコアを音声で案内します。

## 基本操作

| 操作 | パソコン | スマートフォン・タブレット |
|---|---|---|
| ラケットを左右に動かす | 左右矢印キー | 対応端末を水平に持ち、体を左右に動かす |
| サーブの準備・返事・サーブ・返球 | Spaceキー | 画面をタップ |
| 試合を中断する | Escapeキー | 中断ボタンをタップ |

球の音が近づいたら、ラケットの横位置を合わせて返球します。スクリーンリーダー使用時は、通常のタップの代わりにダブルタップで操作します。

中断メニューでは再開、操作方法の確認、TOPへの移動ができます。TOPに戻って試合を終了すると、進行状況は失われます。試合終了後や中断画面から難易度を選び直して、新しい試合を始めることもできます。

## 表示・音声・スマートフォンの設定

起動画面で次の設定を変更できます。

- **配色**：標準、黒背景・白文字、白背景・黒文字、黒背景・黄色文字。
- **文字サイズ**：100%、125%、150%、200%。メニュー・得点・案内に適用します。
- **音声の速さ**：0.5〜2.0倍。

スマートフォンから接続する場合は、サーバーを起動したパソコンと同じWi-Fiに接続し、サーバーに表示されたLAN内のURLを開きます。端末の設定で「体を左右に動かしてラケットを操作する」をオンにし、センサーの許可を求められたら許可してください。

センサーの利用可否は端末・ブラウザ・接続方法によって異なります。LAN内のHTTP接続で画面を開けても、センサーが使えない場合があります。その場合はHTTPSでの利用環境を用意するか、外付けキーボードを使ってください。

対象環境はWindows 11のChrome・Edge・Firefox、Androidの対応ブラウザ、iPhone・iPadのSafariなどです。このうちWindowsのFirefox・Chrome・EdgeとAndroidのChromeは、ユーザーによるプレイ検証済みです。

## 試合のルール

- 1ゲームは11点先取です。10対10になった後は、2点差がつくまで続きます。
- 先に2ゲーム取ると勝ちです（最大3ゲーム）。
- サーブは2ポイントごとに交替します。10対10以降は1ポイントごとに交替します。
- 1ゲームが長引くと、レシーバーが7回返球した時点でレシーバーの得点になる特別ルールが始まることがあります。

卓球のルールを参考にしています。遊びやすさのため、一部のルールはゲーム用に調整しています。

## 困ったとき

- **音が出ない**：開始ボタンを押したか、端末・ブラウザの音量とイヤホン接続を確認します。必要なら再読み込みして開始し直します。
- **スマートフォンで動かない**：センサー設定・許可・接続方法を確認します。端末を傾けるのではなく、水平に持って体を左右に動かします。
- **ページが開かない**：サーバーが起動しているか、表示されたURLとポート番号が合っているか確認します。
- **更新が反映されない**：最新版の `stt.exe` に置き換えて起動し、ブラウザを再読み込みします。画面下部の番号と `stt.exe --version` を確認してください。
