サウンドテーブルテニス (STT) オンライン リリースノート

=========================================
バージョン 3.5.0 (2026年8月18日リリース)
-----------------------------------------
【変更内容】
・Web Audio API による本格的な HRTF 3D空間音響（PannerNode）を実装し、相手コート奥（Z = -3.8m）から自陣守備ライン（Z = -0.6m）へ迫るリアルな奥行き・立体定位を表現しました。
・ボールが手前に向かって迫ってくる際、手元までの残り距離に応じてボール内金属球の刻み周期（ラトル周波数）が加速する動的変調を導入し、ボールが手元に届く「時間間隔（テンポ・タイミング）」を耳だけで正確に掴めるようにしました。
・STT公式ルールブック（2019年版）に準拠し、エンドフレーム内側面に当たった際の「セーフ」、飛び出し時の「アウト」、守備コート内停止時の「ストップボール」、前コート停止時の「前コートストップ」の判定ロジックを実装しました。
・主審の宣告コールを公式ルールブック審判法（27ページ）に定められた手順（[終了の理由] → 「ポイント」 → [選手名] → [スコア]）に統一しました。
・最新の判定・音響ロジックを反映した WebAssembly バイナリ（docs/main.wasm）および Windows 実行バイナリ（stt.exe）を再ビルドしました。

バージョン 3.4 (2026年8月13日リリース)
-----------------------------------------
【変更内容】
・ラリー中にボールが守備ラインに近づくと鳴っていた「かちかち」という接近通知ビープ音を削除しました。この音がボール追跡の集中を妨げているというフィードバックを受けたための対応です。
・ボール転がり音（シャラシャラ音）・打球音・ラケット移動音・歓声音などのコアサウンドデザインはそのまま維持しています。
・`playBeep()` メソッド、`updateApproachBeep()` メソッド、全呼び出し箇所、および関連する状態管理プロパティを `docs/app.js` から完全に削除しました。

バージョン 3.3 (2026年6月16日リリース)
-----------------------------------------
【変更内容】
・オンライン対戦におけるセッション乗っ取りリスクを低減するため、サーバー側での接続時にクライアントIDを自動生成（sv-xxx形式）してクライアント提供IDを上書きする処理を追加しました。
・CheckOrigin にインターネット公開時のCSRF警告コメントを追加しました。
・リザルト画面での不要なリソース消費を削減するため、finishMatch() の先頭でゲームループ（stopLoop()）を停止し、物理計算や描画が走り続けてしまう問題を修正しました。
・Alt + Tab キー等での画面切り替え時にチャージ状態が残留する問題を修正するため、visibilitychange イベントを監視して非表示時にチャージ状態（isCharging）をリセットする処理を追加しました。
・オンライン再戦時に片方のプレイヤーだけゲームが開始しない非対称バグを解決するため、rematch_accept 送信側も startNewMatch() を呼び出すように修正しました。
・Go 1.20 以降の仕様に伴う非推奨 API の削除として、WASM 側（main_wasm.go）から rand.Seed および不要な time パッケージのインポートを削除しました。
・上記変更を反映し、WASM ファイルを再ビルドしました。

バージョン 3.2 (2026年6月15日リリース)
-----------------------------------------
【変更内容】
・docs/styles.css 末尾の network-error-box 周りの重複定義を削除し、アニメーションとシャドウ付きの正しい定義に統一しました。
・ゲーム終了後もアニメーションループが走り続ける問題を解決するため、cancelAnimationFrame(rafId) で描画ループを確実に停止する stopLoop() を実装し、quitGame() 内で呼び出すように修正しました。
・Canvasネット断面図のボール描画時に、2つの arc() の間に beginPath() を追加し、描画が繋がってしまう問題を解決しました。
・オンライン対戦の再戦同期ロジックにおいて、finishMatch() 時には offer のみ送信し、accept は「もう一度プレイ」ボタンが押されたときのみ送信するように分離し、同期の不具合を修正しました。
・音声速度スライダーの説明文における誤字（「　10」→「1.0」、「小咑利」→「スムーズ」）を修正しました。
・音声速度の aria-label 内における最大・最小表記の誤りを修正しました。

バージョン 3.1 (2026年6月14日リリース)
-----------------------------------------
【変更内容】
・難易度（Easy/Normal/Hard）に応じたCPUの返球横速度および縦加速を調整し、対戦バランスを強化しました。
・CPUサーブに「直球」「左流し」「右流し」の3種類のバリエーションを追加しました。
・Hard モードにおけるボールの縦速度（vy）の加速率を 1.05倍から1.12倍に強化し、難易度を向上させました。
・CPUがボールを打ったタイミングで、スクリーンリーダー（sr-announcer）を経由してプレイヤーへ音声で通知する機能を追加しました。
・CPU対戦時の勝者アナウンスにおいて、「プレイヤー2」と読み上げられていた不具合を「CPU」に修正しました。
・Easy 難易度での「CPU固定サーブ」を廃止し、2ポイントごとのサーブ権交代制を適用しました。
・ポイント獲得から2秒が経過した際、ラリーを「スキップ可能」である旨をスクリーンリーダーへ通知するように改善しました。

バージョン 3.0 (2026年6月13日リリース) - メジャーアップデート
-----------------------------------------
【変更内容】
・CPU戦（Normal/Hard）において2ポイントごとにサーブ権が交代する機能を導入し、プレイヤー側からサーブを打つSTT本来の掛け合いを体験できるようにしました。
・スペースキーまたは画面タップの長押し（最大1.5秒）によりサーブ速度を変化させるチャージサーブ機能を追加し、長押し中にチャージ音が上昇するピッチ合成を再生するようにしました。
・打ち返し判定の判定幅を難易度別に調整（Easy=50px / Normal=30px / Hard=20px）しました。
・得点後の4秒間のインターバル待機中に、スペースキー押下やタップ操作で即座に次のラリーへ移行できるスキップ機能を実装しました。
・試合結果画面において勝者と最終スコアを表示し、「もう一度プレイ」または「メニューに戻る」を選択できるように改善しました（6秒の自動退出は廃止）。
・ボールが通過した横位置（左/中央/右）の方向から失点音が鳴るようにし、ミス方向ガイド音のステレオパンニングに対応しました。
・ボール停止時に、そのX座標に応じたステレオ定位で「コトン」という停止音を再生する処理を追加しました。
・ボール転がり音の音量計算式を Math.log1p に変更し、低速域での音量変化を豊かにすることで、リアルな転がりの減速感を表現しました。
・ウェルカム画面に音声速度スライダー（0.5〜2.0倍）を追加し、設定値を localStorage に保存して永続化する機能を追加しました。
・WebSocket接続を維持したまま、対戦終了後に「もう一度プレイ」ボタンで同期して再戦できるリマッチ機能を実装しました。
・オンライン対戦時の切断後5秒以内に同じルーム・クライアントIDで再接続すれば、試合を継続できる猶予処理を追加しました。
・ルームIDを入力して接続することで、最大5名まで対戦を観戦できる観戦モードを追加しました。
・ゲームの各種設定（難易度、チルトON/OFF、サーバーアドレス、音声速度）を localStorage に保存し、次回起動時も維持されるようにしました。

バージョン 1.1 (2026年6月3日リリース)
-----------------------------------------
【変更内容】
・オンライン対戦におけるWebSocket通信とゲーム同期の不具合（4件）を修正しました。
  1. ping メッセージが対戦相手に誤ってブロードキャストされる問題を修正（サーバー側でインターセプトし pong を返す）。
  2. パドル位置送信の過剰な負荷を抑えるため、30msのスロットル処理をクライアント側に実装。
  3. ネットワーク遅延によるボール位置のズレを防ぐため、Player2は物理計算をスキップし、serve / ball_hit イベント受信時のみ位置を同期するよう修正。
  4. 得点時のバグを防ぐため、Player2はローカルでの得点判定処理を行わず、ホスト(Player1)から送られる point メッセージに従ってスコアを更新するよう修正。
