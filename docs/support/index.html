Sound Table Tennisとは

Sound Table Tennis（STT）は、音を頼りにプレイできるブラウザ向け卓球ゲームです。特別なアプリをインストールしなくても、対応するWebブラウザからアクセスして遊べます。

現在はCPUとの対戦ができ、実際にブラウザ上でプレイできる状態で公開しています。「これから作りたいゲーム」ではなく、すでに遊べるゲームを、これからさらに育てていく活動です。

画面を見ることだけを前提にせず、音やキーボード操作、スクリーンリーダーでの利用も意識しながら、より多くの人が遊びやすいゲームを目指して改善を続けています。
