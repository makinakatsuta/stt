# サウンドテーブルテニス（STT）

音と音声案内を頼りにプレイする、ブラウザ向けのサウンドテーブルテニスです。視覚に頼らず、ボールの位置・方向・接近を立体音響で確認できます。

## すぐに遊ぶ

1. `stt.exe` を起動します。
2. ブラウザで <http://localhost:8080> を開きます。
3. 「音声を有効化」→「CPU対戦」→難易度を選びます。

ソースから起動する場合は、プロジェクトのルートで次を実行します。

```bash
go run main_server.go
```

## 操作方法

### ボール追従とスマホのタッチ操作

ラケットはボールへ自動追従しません。PCでは左右矢印キー、スマートフォンでは端末の傾き／左右操作で、プレイヤー自身がラケットを動かします。返球はPCではスペースキー、スマートフォンでは画面タップで行います。スマートフォンのスワイプや移動操作の終了は返球として扱いません。

| 操作 | PC | スマートフォン・タブレット |
|---|---|---|
| ラケット移動 | 左右矢印キー | 端末を水平に持ち、体を左右に動かす（チルト操作） |
| サーブ・返球 | Spaceキー | 画面タップ。スクリーンリーダー利用時はダブルタップ |
| メニューに戻る | Escapeキー | 画面の案内に従う |

サーブでは「いきます」「はい」の順に音声案内が流れます。サーブ時はサーブ音とボールの移動音だけを再生し、`racket.m4a` の「コン」は鳴らしません。ボールが近づいたら、左右にラケットを移動してからSpaceキーまたは画面操作で返球します。実際にラケットへ当たったときだけ、`racket.m4a` の「コン」が鳴ります。

## 難易度

- **Easy**：サーブとラリーの球速が遅く、返球判定も広めです。特定回数のラリーを保証する仕組みはなく、毎回通常の判定でプレイします。初心者が左右移動と返球タイミングを練習しやすい設定です。
- **Normal**：標準的な球速と返球率です。サーブは直球・左・右のコースと速度が変化します。
- **Hard**：高速球と鋭いコースが中心です。CPUのサーブは次の割合で音源と速度を選びます。
  - 速いサーブ（`serve3.m4a`）：60%
  - `serve1.m4a`：20%
  - `serve2.m4a`：20%

## 音源

サーブ音は難易度に応じて次の実録音源を使用します。

- Easy：`sounds/serve1.m4a`
- Normal：`sounds/serve2.m4a`
- Hard：`sounds/serve3.m4a`
- HardのCPUサーブ：上記3音源を重み付きランダム再生

返球時は `racket.m4a`、ボール移動中は `rally.m4a` のゴロゴロ音、ボールがエンドフレームを1回だけ受けてコート外へ落ちる時は `out.m4a`、エンドフレームに2回当たってコート上に残る成功判定時は `SMASH.m4a` を使用します。アウト系の判定では `out.m4a` だけを1回再生して終了します。サーブ時はサーブ専用音源のみを再生します。音はボールの左右位置と距離に合わせて3D定位されます。Easyのゴロゴロ音は短い音源をループし、1回のサーブ・ラリーにつき約5〜6秒継続します。

ブラウザの制限により、最初に「音声を有効化」ボタンを押してください。音量を上げすぎず、周囲の安全を確認して遊んでください。

## ルール概要

- 1ゲーム11点先取です。
- 10対10以降は2点差がつくまで続きます。
- 通常は2ポイントごとにサーブ権を交替し、10対10以降は1ポイントごとに交替します。
- サービスフォルト、ネット、セーフ、アウト、ボール停止などを判定します。
- 3ゲーム中2ゲームを取るとマッチ勝利です。

現在プレイできるのはCPU対戦です。オンライン対戦機能は一時停止中です。
