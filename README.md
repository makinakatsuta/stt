# サウンドテーブルテニス（STT） オンライン

音を聞いてボールの位置を判断し、自分でラケットを左右に動かして返球するブラウザゲームです。
**ヘッドホンまたはイヤホンでのプレイを強くおすすめします。**

視覚に障害のある方も遊べるよう、音声案内、スクリーンリーダー向けの通知、各種アクセシビリティ設定（配色・文字サイズなど）を備えています。現在は「CPU対戦」がプレイ可能です（※オンライン対戦は一時停止中）。

現在の最新リリース：**v3.31.28**（2026-09-25）  
各バージョンの追加機能・改善・修正内容は、[リリースノート](release-notes.txt)をご覧ください。

---

## 🚀 はじめて遊ぶ

### Windowsでの起動手順

1. [リリースページ](https://github.com/makinakatsuta/stt/releases/latest) から最新の `stt.exe` をダウンロードします。
2. ダウンロードした `stt.exe` を実行します（ゲームに必要な画面・音源データなどはすべてこのファイルに含まれています）。
3. ブラウザを開き `http://localhost:8080` にアクセスします。（※黒い画面に別のURLが表示された場合は、そちらを使用してください）
4. 「オーディオを有効にして開始する」を選択し、「CPU対戦」から難易度を選んでゲームを開始します。

## 🕹️ 基本操作

どの難易度でも、ラケットの移動と返球は**プレイヤー自身が操作**します。自動追尾はありません。球の音が近づいたら、ラケットの横位置を合わせて返球してください。

| 操作 | パソコン | スマートフォン・タブレット |
|---|---|---|
| **ラケットの移動** | 左右矢印キー | 端末を水平に持ち、体を左右に動かす |
| **サーブ / 返球** | Spaceキー | 画面をタップ |
| **試合の中断** | Escapeキー | 中断ボタンをタップ |

- **スクリーンリーダーをご利用の場合:** 
  プレイ画面の「サーブ・返球」ボタンを実行（Enter/Space または ダブルタップ）することでも操作可能です。このボタンを使う場合、サーブ時の長押しは不要です。（従来のコート領域での操作や、Spaceキーによる操作も引き続き可能です）
- **中断メニュー:** 
  試合を一時停止し、再開、操作方法の確認、難易度選択（TOP）に戻ることができます。TOPに戻って試合を終了すると進行状況はリセットされます。

## 🎯 3つの難易度

| 難易度 | 特徴 |
|---|---|
| **簡単（Easy）** | 球がゆっくりで、返球しやすい練習向けの難易度です。ラリーが長くなりすぎないよう、CPUが一定回数でミスをします。 |
| **ノーマル（Normal）** | 球速やコースに変化がある標準の難易度です。CPUは状況に応じてコースや球速を変え、プレイヤーの空いた側を狙ってきます。 |
| **ハード（Hard）** | CPUの移動が速く、プレイヤーの返球判定も厳しくなります。CPUは速球と遅球を巧みに打ち分けます。 |

得点後は、判定・得点者・現在のスコアを音声で案内します。

## ⚙️ 表示・音声・アクセシビリティ設定

起動画面で、環境や見え方に合わせた設定が可能です。設定はブラウザに保存されます。

### 画面と音声の設定
- **読み上げ方式**：「ゲーム内蔵音声（初期設定）」または「スクリーンリーダー」から選択できます。スクリーンリーダー方式を選ぶと内蔵の音声案内を停止し、専用の通知領域のみを更新します。（※球音・打球音はどちらの方式でも再生されます）
- **配色**：標準 / 黒背景・白文字 / 白背景・黒文字（白黒反転） / 黒背景・黄色文字
- **文字サイズ**：100% / 125% / 150% / 200%（メニュー・得点・案内に適用）
- **音声の速さ**：0.5〜2.0倍

### 対象環境・動作確認について
- Windows 11のChrome・Edge・Firefox、Androidの対応ブラウザ、iPhone・iPadのSafariなどを対象としています。
- 全盲の利用者による、WindowsのFirefox・Chrome・Edge、およびAndroidのChrome、iPhoneのSafariなどでのプレイ実績・動作確認報告があります。

### スマートフォンから接続する場合
パソコンで起動した `stt.exe` と同じWi-Fiにスマホを接続し、起動時に表示されたLAN内のURLを開くことでプレイ可能です。
- 端末の傾きや移動で操作する場合は、設定で「体を左右に動かしてラケットを操作する」をオンにし、センサーの利用を許可してください。
- センサーが利用できない環境（HTTP接続による制限など）の場合は、外付けキーボードを使用するか、HTTPS化の手順を踏む必要があります。

## 🏓 試合のルール

現実のサウンドテーブルテニスのルールを参考に、遊びやすく調整しています。

- **勝利条件**: 1ゲーム11点先取で、先に2ゲーム取った方の勝ち（最大3ゲームマッチ）。
- **デュース**: 10対10になった後は、2点差がつくまで続きます。
- **サーブ権**: 2ポイントごとに交替（10対10以降は1ポイントごと）。
- **促進ルール**: 1ゲームが長引いた場合、レシーバーが7回返球に成功するとレシーバーの得点になる特別ルールが発動することがあります。

## 💡 困ったとき

- **音が出ない**
  開始ボタンを正しく押したか、端末やブラウザの音量設定、イヤホンの接続を確認してください。解決しない場合はページを再読み込みしてください。
- **スマートフォンでラケットが動かない**
  センサー設定・許可がオンになっているか確認してください。操作のコツとして、端末を「傾ける」のではなく「水平に持ったまま体を左右に動かす」ようにしてください。
- **ページが開かない**
  `stt.exe` が正しく起動しているか、入力したURLやポート番号が間違っていないか確認してください。
- **アップデート（更新）が反映されない**
  最新版の `stt.exe` に置き換えて起動し、ブラウザのキャッシュをクリア（再読み込み）してください。画面下のバージョン表記、または `stt.exe --version` で現在のバージョンを確認できます。
