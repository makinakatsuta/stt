# サウンドテーブルテニス（STT）

音を手がかりに遊ぶ、ブラウザ版のサウンドテーブルテニスです。ボールの位置や近づき方を音で確認し、ラケットを左右に動かして打ち返します。視覚に頼らず遊べるよう、音声案内とスクリーンリーダーにも対応しています。

まずはヘッドホンまたはイヤホンを使い、Easy（簡単）で遊ぶのがおすすめです。パソコンだけでなく、同じネットワーク上のスマートフォンやタブレットからもプレイできます。

## 今回の改善点（2026年9月3日）

- プレイヤーが移動した瞬間だけ、控えめな音量で `Footsteps.m4a` を再生します。
- 返球処理中や移動していない時には、足音を再生しません。
- ストップボール時は、ボールの転がり音を必ず即時停止します。

## まず遊んでみる

### パソコンの場合

1. `stt.exe`を起動します。
2. ブラウザで <http://localhost:8080> を開きます。
3. 最初の画面で「音声を有効化」を押します。音声を使うゲームなので、最初に必ず押してください。
4. 「CPU対戦」から難易度を選びます。初めての場合は「Easy（簡単）」がおすすめです。
5. ヘッドホンまたはイヤホンを接続し、音を聞きながら遊びます。

### スマートフォン・タブレットの場合

1. `stt.exe`を起動しているパソコンと同じネットワークに接続します。
2. パソコンのIPアドレスを使い、スマートフォンのブラウザで `http://パソコンのIPアドレス:8080` を開きます。
3. 「音声を有効化」をタップします。
4. 「体を左右に動かしてラケットを操作する（加速度センサー）」をONにします。
5. iPhoneでは、表示されたモーションセンサーの許可で「許可」を選びます。
6. 「CPU対戦」から難易度を選びます。初めての場合は「Easy（簡単）」がおすすめです。

スマートフォンは画面を水平に持ち、端末を傾けるのではなく、体ごと左右に動かします。ラケットは端末の傾きではなく、左右方向の加速度で動きます。

## 対応ブラウザ

- **対応OS**：Windows 11
- **PCブラウザ**：Google Chrome、Microsoft Edge、Firefox
- Android：Google Chromeなど、モーションセンサーを利用できるブラウザ
- iPhone：Safari、iPhone版Google Chrome
- iOSは18以降を対象にしています。iOS 26専用の機能は使っていません。
- iPhone版ChromeもiOSの仕組みにより、センサー許可などはSafariと同じ扱いになります。

Windows 11では、Google Chrome・Microsoft Edge・Firefoxの各ブラウザでプレイできます。音声を使うゲームのため、いずれのブラウザでも最初に「音声を有効化」を押してください。

スマートフォンでセンサー許可が表示されない場合は、ページを再読み込みしてから「音声を有効化」をもう一度タップしてください。公開サーバーで使う場合はHTTPSが必要です。`localhost`で使う場合はHTTPでも動作します。

## 操作方法

| 操作 | パソコン | スマートフォン・タブレット |
|---|---|---|
| ラケットを左右に動かす | 左右矢印キー | 端末を水平に持ち、体を左右に動かす |
| サーブ・返球 | Spaceキー | 画面をタップ。スクリーンリーダー利用時はダブルタップ |
| メニューに戻る | Escapeキー | 画面の案内に従う |

ラケットは、ボールが来る横位置に合わせます。ボールがラケットの近くに来たタイミングで、Spaceキーまたは画面操作を行って返球します。返球できたときは打球音が鳴ります。

サーブでは、音声案内の「いきます」「はい」に続いてボールが動き始めます。

## 音の聞き分け

- ボールの転がり音：ボールが移動しています。音の大きさや左右の位置から、近づき方を確認します。
- プレイヤーの足音：プレイヤーが左右に移動した瞬間に短く鳴ります。返球音ではありません。
- ラケット移動音：「カチカチ」という短い音です。ラケットを左右に動かしたときに鳴り、音もラケットの左右位置に合わせて移動します。
- 中央の目印音：ラケットがコート中央に入ったときに鳴ります。対応端末では短い振動も起こります。
- 打球音：「コン」という音です。ラケットでボールを返せたときに鳴ります。
- ネット・フレーム・アウトの音：ボールの結果を知らせます。
- 音声案内：サーブ、得点、試合の状態などを読み上げます。

ゲームを始める前に、必ず「音声を有効化」を押してください。これはスマートフォンやブラウザが、ユーザーの操作なしに音を出すことを制限しているためです。音が聞こえないときは、ブラウザの音量、端末の音量、イヤホンの接続を確認してください。

## 難易度

- **Easy（簡単）**：ボールが遅く、返球しやすい初心者向けです。CPUは適度にミスをするため、ラリーの練習に向いています。
  - 2026年8月30日の調整で、CPUの強さだけを従来比5%引き上げました。
  - 低速サーブ、左右へ導くサーブコース、ラリー練習向けのプレースタイルは変わっていません。
- **Normal（普通）**：標準的な難しさです。基本操作に慣れた後に向いています。
- **Hard（難しい）**：Normalよりラケットの移動や返球判定が厳しくなります。Normalより難しい操作に挑戦したい場合に向いています。

今回のEasy調整では、Normal／Hard、ゲームのルール、操作方法、初心者向けのコンセプトは変更していません。

## ルールの概要

- 1ゲームは11点先取です。
- 10対10になった後は、2点差がつくまで続きます。
- 通常は2ポイントごとにサーブ権が交替します。
- 10対10以降は1ポイントごとにサーブ権が交替します。
- 3ゲーム中2ゲームを取るとマッチ勝利です。
- サービスフォルト、ネット、フレーム、アウト、ボール停止などを判定します。

現在はCPU対戦を利用できます。オンライン対戦は一時停止中です。

## うまく動かないとき

### 音が出ない

1. 最初の画面で「音声を有効化」を押したか確認します。
2. ブラウザと端末の音量を確認します。
3. イヤホンを接続している場合は、出力先を確認します。
4. ページを再読み込みして、もう一度音声を有効化します。

### スマートフォンでラケットが動かない

1. チルト操作の設定がONになっているか確認します。
2. iPhoneではモーションセンサーの許可を確認します。
3. 画面を水平に持ち、端末を傾けるのではなく体を左右に動かします。
4. 設定項目が表示されない場合は、ページを再読み込みします。

### 音は出るが「カチカチ」音だけ聞こえない

ラケットを実際に左右へ動かしているか確認してください。移動が小さい場合や、センサーが動きを検出していない場合は鳴りません。スマートフォンでは、音声有効化をタップした直後から操作を始めると安定します。

### 移動時の足音が聞こえない

プレイヤーが実際に左右へ移動した時だけ再生されます。移動量が小さい場合は鳴らないことがあるため、左右矢印キーまたは体の左右移動を少し大きく行ってください。足音はボール音を聞き取りやすくするため、控えめな音量です。

## 起動方法（開発者向け）

プロジェクトのルートで次を実行します。

```bash
go run main_server.go
```

配布版は`stt.exe`を起動します。`stt.exe`と`docs`フォルダは同じ場所に置いてください。`docs`フォルダを移動・削除すると、画面や音源を読み込めません。

## ファイル構成

- サーバー：`main_server.go`
- 画面：`docs/index.html`
- フロントエンド：`docs/app.js`、`docs/js/`
- 音源：`docs/sounds/`
- 物理演算：`main_wasm.go`、`docs/main.wasm`

画面やフロントエンド、`docs/main.wasm`を更新した場合、通常は`stt.exe`の再ビルドは不要です。更新した`docs`フォルダを`stt.exe`と同じ場所に置いてください。
