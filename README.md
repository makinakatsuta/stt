# サウンドテーブルテニス（STT）

音と音声案内を頼りにプレイする、ブラウザ向けのサウンドテーブルテニスです。視覚に頼らず、ボールの位置・方向・接近を立体音響で確認できます。

## はじめて遊ぶ方へ

1. `stt.exe` を起動します。
2. ブラウザで <http://localhost:8080> を開きます。
3. 最初の画面で「音声を有効化」を押します。
4. 「CPU対戦」を選び、まずは **Easy（簡単）** を選びます。
5. ヘッドホンまたはイヤホンを使い、音声案内とボール音を聞きながら遊びます。

音が聞こえないときは、ブラウザの音量と端末の音量を確認してください。ゲーム開始後は、ボールが近づく音を聞いてラケットを動かし、タイミングを合わせて返球します。

詳しい判定方法、音の意味、更新内容は[リリースノート](release-notes.txt)を参照してください。

ソースから起動する場合は、プロジェクトのルートで次を実行します。

```bash
go run main_server.go
```

## 操作方法

### ラケットの動かし方と返球

ラケットは自動では動きません。ボールの音を聞きながら、自分でラケットを左右に動かします。ボールが近づいたら、ラケットをボールの横位置に合わせて返球してください。

| 操作 | PC | スマートフォン・タブレット |
|---|---|---|
| ラケット移動 | 左右矢印キー | 端末を水平に持ち、体を左右に動かす（チルト操作） |
| サーブ・返球 | Spaceキー | 画面タップ。スクリーンリーダー利用時はダブルタップ |
| メニューに戻る | Escapeキー | 画面の案内に従う |

サーブでは「いきます」「はい」の順に音声案内が流れます。ボールが近づいたら、左右にラケットを動かしてからSpaceキーまたは画面操作で返球します。実際にラケットへ当たったときに打球音が鳴ります。

## 難易度

- **Easy（簡単）**：ボールが遅く、返球しやすい初心者向けです。まずはこのモードで、左右移動と返球のタイミングを練習してください。
- **Normal（普通）**：標準的な難しさです。球速やコースが変化するため、慣れてきたら挑戦してください。
- **Hard（難しい）**：Normalより判定が10%厳しく、速い球や鋭いコースにも対応する必要があります。

難易度ごとの具体的な数値や判定の詳細は、[リリースノート](release-notes.txt)に記載しています。

## 音について

ボールの左右位置や距離は、音の左右の広がりや大きさで伝えます。返球音、ボールの移動音、アウト音などを手がかりにプレイしてください。

ブラウザの制限により、最初に「音声を有効化」ボタンを押してください。音量を上げすぎず、周囲の安全を確認して遊んでください。

音源の種類や再生タイミングなど、詳しい仕様は[リリースノート](release-notes.txt)を確認してください。

## ルール概要

- 1ゲーム11点先取です。
- 10対10以降は2点差がつくまで続きます。
- 通常は2ポイントごとにサーブ権を交替し、10対10以降は1ポイントごとに交替します。
- サービスフォルト、ネット、セーフ、アウト、ボール停止などを判定します。
- 3ゲーム中2ゲームを取るとマッチ勝利です。

現在プレイできるのはCPU対戦です。オンライン対戦機能は一時停止中です。

## ファイル構成（配布・開発者向け）

- サーバー：`main_server.go`
- 画面：`docs/index.html`
- フロントエンド：`docs/app.js`、`docs/js/`
- 音源：`docs/sounds/`
- 物理演算：`main_wasm.go`、`docs/main.wasm`

`stt.exe`は、同じ場所にある`docs`フォルダをブラウザへ配信します。`docs`フォルダは削除・移動せず、必ず`stt.exe`と同じ場所に置いてください。`docs/main.wasm`やフロントエンドだけを更新した場合、`stt.exe`の再ビルドは不要です。
