# サウンドテーブルテニス（STT）

音を聞いてボールの位置を判断し、ラケットを左右に動かして返球するブラウザゲームです。ヘッドホンまたはイヤホンでのプレイをおすすめします。

[ブラウザで遊ぶ](https://soundtabletennis.com/)

## 遊び方

1. 起動画面で必要に応じて配色、文字サイズ、読み上げ方式、音声の速さを設定します。
2. 「ゲームを開始する」で音を有効にし、「CPU対戦」から難易度を選びます。
3. 球音を聞き、ラケットの横位置を合わせて返球します。ラケットは自分で操作します。

1ゲーム11点、2ゲーム先取で勝利です。10対10以降は2点差が必要です。サーブ権は2ポイントごと、10対10以降は1ポイントごとに交替します。得点や判定は音声で案内します。

## PCでの操作

- 左右矢印キー：ラケットを移動。
- 数字キー1・2・3（テンキーも可）：自分のサービスで、「プレー」の前にサーブ1・2・3を選択。「サーブ1」「サーブ2」「サーブ3」ボタンでも選べます。選択だけではボールを打ちません。
- Spaceキーの単押し：準備の「いきます」、レシーブの返事「はい」、サービス、ラリー中の返球。長押しによるチャージはありません。
- Escapeキー：中断メニュー。再開、操作方法の確認、TOPへ戻る操作ができます。

ゲーム画面のタップでも、Spaceキーと同じゲーム操作ができます。

## スマートフォンでの操作

設定で傾き操作をオンにし、センサーの利用を許可します。画面を上に向け、動かしたい側を下げてラケットを移動し、水平に戻して止めます。

自分のサービスでは「サーブ1」「サーブ2」「サーブ3」のいずれかをタップして選びます。準備、返事、サービス、返球はゲーム画面のタップで実行できます。長押しは不要です。

## スクリーンリーダーでの操作

起動画面で読み上げ方式を「スクリーンリーダー」に設定してください。球音・打球音も再生されます。

NVDAでは、自分がサーバーのとき「プレー」の前に数字キー1～3、または「サーブ1」「サーブ2」「サーブ3」ボタンからサーブを選択できます。必要に応じてフォーカスモードを使用してください。

VoiceOver・TalkBackでは、「サーブ1」「サーブ2」「サーブ3」ボタンをスワイプまたはタッチ探索し、ダブルタップして選択します。iPhoneとAndroidの基本操作は同じです。

選択後に「プレー」が案内されます。プレイ中の不要なボタンや操作領域は読み上げません。NVDAではSpaceの単押しで操作できます。

プレイ中の常設操作ボタンは「中断メニュー」だけです。中断すると再開、操作方法、読み上げ方式、ラケット位置のリセット、TOPへ戻る操作を利用できます。

## 難易度

| 難易度 | 特徴 |
|---|---|
| Easy | 球がゆっくりで返球しやすい、初めての方向け。 |
| Normal | 球の速さや方向に変化がある、操作に慣れた方向け。 |
| Hard | Normalより速く、左右の配球も厳しい、上級者向け。 |

## サービス手順

1. 自分がサーバーになったら、サーブ1～3を選択します。選択時間は10秒制限に含まれません。
2. 主審の「プレー」から10秒以内に、サーバーが「いきます」を実行します。
3. 「いきます」から5秒以内に、レシーバーが「はい」を実行します。
4. 「はい」から5秒以内に、サーバーがサービスを打ちます。

準備・返事・打球は、それぞれSpaceの単押しまたはゲーム画面のタップで実行します。CPUの準備・返事・サービスは自動です。時間超過はオーバータイムとなり、相手に1点入ります。

サーブ1は安定型、サーブ2はバランス型、サーブ3は攻撃型です。CPU対戦ではサーブの種類によってサービスエースを狙えます。選択した種類は、そのサービスが終わるまで変更できません。

## 主な機能・Windows版

配色・文字サイズ・読み上げ方式・音声速度を設定でき、設定はブラウザに保存されます。オンライン対戦は現在準備中です。

[Windows版](https://github.com/makinakatsuta/stt/releases/latest)の `stt.exe` は、画面や音源を含む単体実行ファイルです。起動後、表示されるURL（通常は `http://localhost:8080`）をブラウザで開きます。同じWi-Fiのスマートフォンからは、表示されるLAN内URLを開けます。センサーが利用できない環境では外付けキーボード等が必要です。

音が出ない場合は開始操作、端末の音量、イヤホンの接続を確認してください。[支援ページ](https://soundtabletennis.com/support/)も参照できます。

## 開発・ライセンス

GoとJavaScriptで開発しています。Windows版は `GOOS=windows`、`GOARCH=amd64` で `go build -trimpath -o stt.exe main_server.go` を実行します。WASMソースを変更した場合は `GOOS=js`、`GOARCH=wasm` で `go build -o docs/main.wasm main_wasm.go` を実行します。回帰テストは `node --test tests/*.test.cjs` です。
