# サウンドテーブルテニス（STT）

視覚障害者向け競技「サウンドテーブルテニス（STT）」を、音声・音響中心で体験するブラウザゲームです。画面を見なくても、審判の音声、ボールの転がり音、左右の音像を頼りにプレイできます。

同梱の2019年版STTルールブックを基準に、サービスの掛け声、11点制、デュース、2点ごとのサービス交替、セーフ・アウト・ストップなどを実装しています。ゲーム構成は、従来どおり3ゲーム中2ゲーム先取です。

## 今回の返球改善

ラリー中は、Spaceキーまたは画面タップで返球します。返球判定を次のように改善しました。

- ボールが自分側へ向かっていることを確認して返球します。
- 守備ライン付近の受付範囲を拡大しました。
- ボールの半径を考慮し、ラケット端付近でも当たりやすくしました。
- 早めに押した入力を180ms保持し、ボールが判定範囲に入った次の物理フレームで再判定します。
- Easy / Normal / Hard の順に、返球受付の広さが異なります。
- 返球成功時だけ打球音・スイング音・エフェクトを再生します。

入力が早すぎたり遅すぎたりしても、短い入力バッファによって返球しやすくなっています。ラケットは左右矢印キー、または対応端末のチルト操作で移動します。

## まず知っておきたいこと

- 現在プレイできるのはCPU対戦です。
- オンライン対戦は一時停止中で、メニューから選ぶと利用停止の案内が表示されます。
- 音声を有効にするため、最初に「音声を有効化」を押してください。
- 音量を上げすぎず、周囲の安全を確保してプレイしてください。スマートフォンでは端末を水平に持ちます。

## 起動方法

### Windowsで遊ぶ

1. `stt.exe` を起動します。
2. ブラウザで `http://localhost:8080` を開きます。
3. 音声を有効化し、「CPU対戦」から難易度を選びます。

### ソースコードから起動する

```bash
go run main_server.go
```

起動後、ブラウザで `http://localhost:8080` を開いてください。

## 操作方法

### PC・外付けキーボード

| 操作 | キー |
|---|---|
| ラケットを左へ移動 | `←` |
| ラケットを右へ移動 | `→` |
| サーブ・返球・決定 | `Space` |
| 一時停止・戻る | `Escape` |

### スマートフォン

- ウェルカム画面で加速度センサーを有効にすると、端末を水平に持って体を左右へ動かしてラケットを操作できます。
- iPhoneでは、表示されたセンサー利用許可を承認してください。
- 画面のタップが `Space` と同じアクションになります。VoiceOverやTalkBackではダブルタップを使います。
- 「ラケット位置をリセット」でラケットを中央へ戻せます。
- センサーを使わない場合は、Bluetoothキーボードでも操作できます。

## STTのプレイ手順

1. 主審の「プレー」を聞いて準備します。
2. サーバーがボールを静止させ、「いきます」と発声します。
3. レシーバーが「はい」と返答します。
4. サーバーは返答後にサービスを打ちます。
5. ボールはネット下の隙間を通って転がります。左右の音像と音量の変化を聞き、ラケットを合わせて返球します。
6. ラリーの結果に応じて、主審が理由・ポイント・スコアを読み上げます。

サービスの「いきます」、レシーバーの「はい」、サービス実行には制限時間があります。時間を超えるとオーバータイムになります。

## スコアとゲーム進行

- 1ゲームは11点先取です。
- 10対10以降は、2点差がつくまで続きます。
- 通常は合計2ポイントごとにサービス権が交替します。
- 10対10以降は1ポイントごとにサービス権が交替します。
- 3ゲーム中2ゲームを取ると試合に勝利します。
- 得点後は4秒待つか、`Space`またはタップで次へ進めます。

## 音響設計

- ボールの転がり音は、相手コートから自分の守備ラインへ近づくにつれて、音量・音色・奥行きが変化します。
- 使用する音源は `sounds/` にある実録音源だけです。ボール転がり音と難易度別サーブ音を読み込み、再生前にモノラルへ統一してから位置情報を加えます。
- サーブ中は `serve1.m4a`、`serve2.m4a`、`serve3.m4a` のいずれかだけを使い、ラリー中は `drop down.m4a` だけを使います。サーブ音からラリー音、ラリー音からサーブ音への代替再生は行いません。
- `sounds/` にないオシレーター音、ノイズ音、合成効果音は再生しません。
- 中央位置に入った瞬間は、音源を追加せず、スマートフォンの短い振動で知らせます。
- ラケット移動時は、位置に応じて左右定位が変わる短い足音を再生します。「カチカチ」音は再生しません。
- サーブチャージ中の電子的な「ピコピコ」音も廃止しています。長押し時間によるサーブ速度の変化は残っています。
- 審判コールやスクリーンリーダー向け案内の読み上げ速度は、ウェルカム画面で0.5〜2.0倍に設定できます。

## 難易度

- **Easy**: 初めてプレイする人向けです。球が遅く、ラケットの自動追従補助と広い返球判定により、操作に慣れながらラリーを練習できます。
- **Normal**: 標準的なCPU速度とサーブです。
- **Hard**: CPUの移動と返球が速く、判定も厳しくなります。

## STTルールとの対応範囲

ゲーム内では、STTのコート寸法、ネット下通過、サービス順序、サービス交替、セーフ・アウト、停止、前コート停止、11点制、デュース、主審コールを再現しています。

実際の競技で審判員が判定する身体接触、ハンドオンテーブル、ムーブテーブル、ダブルヒット、ホールディング、オブストラクションなどは、ブラウザゲームの入力だけでは完全に判定できません。詳細は同梱の [STT_rulebook_all.html](STT_rulebook_all.html) を参照してください。

## 技術構成

- バックエンド: Go、WebSocket
- フロントエンド: HTML、CSS、JavaScript
- 音響: Web Audio API、モノラル音源 + HRTF PannerNodeによる3D定位
- 音声案内: Web Speech API、ARIAライブリージョン
- 描画: Canvas API
- モバイル操作: DeviceMotion API
