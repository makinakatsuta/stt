# サウンドテーブルテニス（STT）

現在のリリース: **v3.31.19**

音を聞いてボールの位置を判断し、ラケットを左右に動かして遊ぶブラウザゲームです。視覚に頼らず遊べるよう、音声案内とスクリーンリーダーに対応しています。

## まず遊ぶ（パソコン）

1. [最新リリース](https://github.com/makinakatsuta/stt/releases/latest)のWindows x64用ZIPを展開し、中の `stt.exe` を起動します。
2. ブラウザで <http://localhost:8080> を開きます。
3. 最初の画面で「音声を有効化」を押します。
4. 「CPU対戦」を選び、難易度を選択します。初めての方は **Easy（簡単）** がおすすめです。
5. ヘッドホンまたはイヤホンを接続して遊びます。

このゲームは音を聞いて操作します。音声を有効化しないとゲーム音が再生されない場合があります。

## 基本操作

| やること | パソコン | スマートフォン・タブレット |
|---|---|---|
| ラケットを左右に動かす | 左右矢印キー | 端末を水平に持ち、体を左右に動かす |
| サーブ・返球する | Spaceキー | 画面をタップ |
| プレイを中断する | Escapeキー | 「中断メニュー」をタップ |

ボールの転がり音を聞き、音の左右位置からボールの方向を判断します。ボールがラケットに近づいたら、ラケットをボールの横位置に合わせてSpaceキーまたは画面タップで返球します。

サーブや返球のタイミングは音声でも案内されます。スクリーンリーダーを使用している場合は、画面タップの代わりにダブルタップで操作できます。

## スマートフォン・タブレットで遊ぶ

1. `stt.exe` を起動したパソコンと同じWi-Fiに接続します。
2. パソコンのIPアドレスを使い、`http://パソコンのIPアドレス:8080` を開きます。
3. 「音声を有効化」をタップします。
4. 「体を左右に動かしてラケットを操作する（加速度センサー）」をONにします。
5. センサーの許可が表示されたら「許可」を選びます。
6. 「CPU対戦」から難易度を選びます。

端末を傾けるのではなく、端末を水平に持って体を左右に動かしてください。センサーの許可が表示されない場合は、ページを再読み込みしてから設定をやり直します。公開サーバーでセンサーを使う場合はHTTPSが必要です。

## 対応環境

- **パソコンOS**：Windows 11
- **パソコンブラウザ**：Google Chrome、Microsoft Edge、Firefox
- **Android**：モーションセンサーを利用できるブラウザ
- **iPhone・iPad**：Safari、iPhone・iPad版Google Chrome（iOS 18以降）

## 難易度

- **Easy（簡単）**：ボールが遅く、返球しやすい初心者向け。ラリー練習を重視した従来の速度です。
- **Normal（普通）**：平均的な選手と対戦するイメージの標準モード。ラリー時間と返球の難しさを標準にしています。
- **Hard（難しい）**：強い選手を想定した上級者向け。Normalより返球が速く、試合展開も早くなります。

難易度によってラリーの速さとCPUの返球の厳しさが変わります。Easyの初心者向けコンセプトは維持し、NormalとHardでは長引きにくい試合展開を目指しています。

中断メニューでは「再開」で試合を続ける、「操作方法」で説明を確認する、「TOPに戻る」で試合を終了することができます。操作方法を閉じると中断メニューに戻ります。TOPへ戻る際は進行状況が失われることを確認します。

試合終了後や中断メニューから、Easy・Normal・Hardを選んで新しい試合を開始することもできます。

## ルールの概要

- 1ゲーム11点先取です。
- 10対10以降は2点差がつくまで続きます。
- 3ゲーム中2ゲームを取るとマッチ勝利です。
- サーブ権は通常2ポイントごと、10対10以降は1ポイントごとに交替します。
- 1ゲームが10分以上続き、9対9または10対8以降の終盤スコアでない場合は、公式ルールに基づく促進ルールを適用します。
- 促進ルール中は、レシーバーが7回返球に成功するとラリーを終了します。

現在利用できるのはCPU対戦です。オンライン対戦は一時停止中です。

## 音が聞こえないとき

1. 最初の画面で「音声を有効化」を押したか確認します。
2. ブラウザと端末の音量、イヤホンの接続を確認します。
3. ページを再読み込みして、もう一度「音声を有効化」を押します。

スマートフォンでラケットが動かない場合は、加速度センサー設定とセンサー許可を確認し、端末を水平に持って体を左右に動かしてください。

## 開発者向け

配布版は `stt.exe` と `docs` フォルダを同じ場所に置いて `stt.exe` を起動します。exe単体をダウンロードする場合も、同じバージョンの `docs` フォルダが必要です。`stt.exe --version` でexeのバージョンを確認できます。

開発時はプロジェクトのルートで次を実行します。

```bash
go run main_server.go
```

画面や音源などの変更履歴、調整内容、確認記録は [release-notes.txt](release-notes.txt) を確認してください。
