# サウンドテーブルテニス（STT）

卓球台上のボールの動きや球音から位置を判断し、ラケットを左右に動かして返球するブラウザゲームです。晴眼者・ロービジョン者・全盲者が、同じルールのゲームを、それぞれ利用できる視覚・音響・音声案内を使って楽しめる設計です。ヘッドホンまたはイヤホンでのプレイをおすすめします。

[ブラウザで遊ぶ](https://soundtabletennis.com/)

## 遊び方

1. 起動画面で必要に応じて配色、文字サイズ、読み上げ方式、音声の速さを設定します。
2. 「ゲームを開始する」で音を有効にし、「CPU対戦」から難易度を選びます。
3. ボールの動きや球音から位置を判断し、ラケットの横位置を合わせて返球します。ラケットは自分で操作します。

1ゲーム11点、2ゲーム先取で勝利です。10対10以降は2点差が必要です。サーブ権は2ポイントごと、10対10以降は1ポイントごとに交替します。得点や判定は音声で案内します。

## ゲーム画面と見やすさ

画面には卓球台、中央のメッシュネットと支柱、ボール、ラケット、得点・ゲーム状態を表示します。台の境界とボールには明確な輪郭があり、ラケットは色に加えて「1」「2」で識別できます。ボールの短い残像は直前の動きを示します。ボールがどこへ来るかを判断して返球するゲーム性を保ち、未来軌道や着地点の予測は表示しません。

起動画面の「画面の見やすさ」で「配色・コントラスト」を選ぶと、標準、黒背景・白文字、白背景・黒文字、黒背景・黄色文字を切り替えられます。配色はゲーム画面の卓球台・ネット・ボール・ラケットにも反映されます。「文字の大きさ」はメニュー・得点・案内を100%・125%・150%・200%に変更します。設定は保存され、次回起動時に復元されます。保存できない環境でも、その回の設定変更は利用できます。

v3.31.46では、拡大時のカード・メニュー・設定欄・得点・中断・試合結果を内容に合わせて折り返すよう改善しました。装飾タイトルだけ画面幅に応じて調整し、「TENNIS STT」をまとめて自然に改行します。本文・操作文字は選んだ拡大倍率を維持し、長い画面は縦にスクロールできます。選択欄は既存のネイティブ選択・ラベル・キーボード操作を保ち、閉じた状態の選択値を折り返して表示します。ゲーム画面でも縦スワイプとピンチ拡大を許可し、スクロールのキャンセルを打球として扱いません。

## PCでの操作

- 左右矢印キー：ラケットを移動。
- 数字キー1・2・3（テンキーも可）：自分のサービスで、「プレー」の前にサーブ1・2・3を選択。「サーブ1」「サーブ2」「サーブ3」ボタンでも選べます。選択だけではボールを打ちません。
- Spaceキーの単押し：準備の「いきます」、レシーブの返事「はい」、サービス、ラリー中の返球。長押しによるチャージはありません。
- Escapeキー：中断メニュー。再開、操作方法の確認、TOPへ戻る操作ができます。

ゲーム画面のタップでも、Spaceキーと同じゲーム操作ができます。

## スマートフォンでの操作

設定で傾き操作をオンにし、センサーの利用を許可します。画面を上に向け、動かしたい側を下げてラケットを移動し、水平に戻して止めます。

自分のサービスでは「サーブ1」「サーブ2」「サーブ3」のいずれかをタップして選びます。準備、返事、サービス、返球はゲーム画面のタップで実行できます。長押しは不要です。

## スクリーンリーダーでの操作

起動画面で読み上げ方式を「スクリーンリーダー」に設定してください。球音・打球音も再生されます。

NVDAでは、自分がサーバーのとき「プレー」の前に数字キー1～3、または「サーブ1」「サーブ2」「サーブ3」ボタンからサーブを選択できます。必要に応じてフォーカスモードを使用してください。

VoiceOver・TalkBackでは、「サーブ1」「サーブ2」「サーブ3」ボタンをスワイプまたはタッチ探索し、ダブルタップして選択します。iPhoneとAndroidの基本操作は同じです。

選択後に「プレー」が案内されます。プレイ中の不要なボタンや操作領域は読み上げません。NVDAではSpaceの単押しで操作できます。

Canvas上のボール・残像・台・ネット・ラケットは読み上げ対象にせず、球音・音響定位と必要なサーブ・得点・判定の案内を使って、画面を見ずに操作できる構造です。VoiceOver・TalkBackが名前のないゲーム画面にダブルタップの入力を送るかは端末による実機確認が必要です。送られたクリックはゲーム操作として受け付けます。今回の表示変更後の実機スクリーンリーダー確認と利用者による視認性確認は未完了です。

プレイ中の常設操作ボタンは「中断メニュー」だけです。中断すると再開、操作方法、読み上げ方式、ラケット位置のリセット、TOPへ戻る操作を利用できます。

## 難易度

| 難易度 | 特徴 |
|---|---|
| Easy | 球がゆっくりで返球しやすい、初めての方向け。 |
| Normal | 球の速さや方向に変化がある、操作に慣れた方向け。 |
| Hard | Normalより速く、左右の配球も厳しい、上級者向け。 |

3難易度とも共通の視覚UI・配色設定・音響・音声案内・操作を使います。視覚障害の有無によってゲームルールは変わりません。今回の視覚UI改善では、Easy / Normal / Hardの既存バランスを変更していません。

## サービス手順

1. 自分がサーバーになったら、サーブ1～3を選択します。選択時間は10秒制限に含まれません。
2. 主審の「プレー」から10秒以内に、サーバーが「いきます」を実行します。
3. 「いきます」から5秒以内に、レシーバーが「はい」を実行します。
4. 「はい」から5秒以内に、サーバーがサービスを打ちます。

準備・返事・打球は、それぞれSpaceの単押しまたはゲーム画面のタップで実行します。CPUの準備・返事・サービスは自動です。時間超過はオーバータイムとなり、相手に1点入ります。

サーブ1は安定型、サーブ2はバランス型、サーブ3は攻撃型です。CPU対戦ではサーブの種類によってサービスエースを狙えます。選択した種類は、そのサービスが終わるまで変更できません。

## 主な機能・Windows版

配色・文字サイズ・読み上げ方式・音声速度を設定でき、設定はブラウザに保存されます。オンライン対戦は現在準備中です。

[Windows版](https://github.com/makinakatsuta/stt/releases/latest)の `stt.exe` は、画面や音源を含む単体実行ファイルです。起動後、表示されるURL（通常は `http://localhost:8080`）をブラウザで開きます。同じWi-Fiのスマートフォンからは、表示されるLAN内URLを開けます。センサーが利用できない環境では外付けキーボード等が必要です。

音が出ない場合は開始操作、端末の音量、イヤホンの接続を確認してください。[支援ページ](https://soundtabletennis.com/support/)も参照できます。

## 開発・ライセンス

GoとJavaScriptで開発しています。Windows版は `GOOS=windows`、`GOARCH=amd64` で `go build -trimpath -o stt.exe main_server.go` を実行します。WASMソースを変更した場合は `GOOS=js`、`GOARCH=wasm` で `go build -o docs/main.wasm main_wasm.go` を実行します。回帰テストは `node --test tests/*.test.cjs` です。

回帰テストにはNode.jsと既存の `docs/main.wasm` を使います。3難易度のJS／WASM動作、サーブ・得点・操作・音声案内に加え、ゲームバランスを固定fixtureで保護しています。Normalは既存の `tests/fixtures/normal-balance.json` を維持し、Easy / Hardは視覚UI変更前の挙動を記録したfixtureを追加しました。balanceは `node tests/balance-snapshots.test.cjs` と `node tests/difficulty.test.cjs --contracts-only`、描画は `node tests/canvas-rendering.test.cjs` で確認できます。全テストには長時間の対戦シミュレーションが含まれます。

Canvasテストは描画命令・配色・過去位置だけの残像・予測情報の非表示等を検証します。実画面の見やすさや実機スクリーンリーダーでの操作、音響定位の評価は自動テストとは別に行います。未完了の確認は [ToDo.md](ToDo.md) に記録しています。

任意のChrome実ブラウザ検査は `tests/layout-browser.cjs` です。Playwrightを一時ディレクトリへインストールし、その `node_modules` を `NODE_PATH` に指定して `node tests/layout-browser.cjs` を実行します。既定のChrome以外は `STT_BROWSER` に実行ファイルのパスを指定できます。4文字サイズ×4配色×5画面サイズ、メニュー・プレイ・中断・結果等の9画面のはみ出し、ボタン内の重なり、選択値と設定復元を検査します。1280×720のブラウザ200%／400%ズームに相当する640×360／320×180のリフローも確認します。画像は既定でOSの一時フォルダー内 `stt-layout-results` に保存し、`STT_LAYOUT_ARTIFACTS` で変更できます。実際のブラウザのズーム操作、Safari／Firefox、実機の支援技術と音響評価は別途確認が必要です。
