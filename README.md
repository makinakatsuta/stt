# サウンドテーブルテニス（STT）

音を聞いてボールの位置を判断し、自分でラケットを左右に動かして返球するブラウザゲームです。

**[ブラウザですぐ遊ぶ](https://soundtabletennis.com/)** — インストール不要です。

**ヘッドホンまたはイヤホンでのプレイを強くおすすめします。**

視覚に障害のある方も遊べるよう、音声案内、スクリーンリーダー向けの通知、各種アクセシビリティ設定（配色・文字サイズなど）を備えています。現在は「CPU対戦」がプレイ可能です（オンライン対戦は現在準備中）。

バージョン：**v3.31.42**（2026-10-06）
更新内容や詳しい変更点は、[リリースノート](release-notes.txt)をご覧ください。

今回の更新：Hardモードのゲームバランスを再調整しました。ラリーはできてもCPUが返し続けて得点しにくかった状態を改善し、長いラリーや良いコースへの返球が得点につながりやすくなりました。Normalより難しい位置付けは維持しています。最終Hard調整では、実ブラウザで良好だった現在のNormalのゲームバランスを変更していません。v3.31.41以降の先行作業との差分はリリースノートに記載しています。

v3.31.42のHard再調整は自動テストで確認済みです。最終調整後のWindows＋NVDAでの実プレイは、ユーザーによる検証済みです（2026-10-06）。今回の版のVoiceOver・TalkBackでの実機確認は未実施です。

## 🚀 はじめて遊ぶ

### ブラウザで今すぐ遊ぶ

**[サウンドテーブルテニスを遊ぶ](https://soundtabletennis.com/)**

インストール不要です。パソコンやスマートフォンのブラウザで開けます。

1. ヘッドホンまたはイヤホンを接続して、上のリンクを開きます。
2. 必要に応じて配色・文字サイズ・読み上げ方式を選びます。スクリーンリーダーを使う場合は「スクリーンリーダー」を選んでください。
3. 「ゲームを開始する」を選択して、音声・ゲーム音を有効にします。
4. 「CPU対戦」から難易度を選びます。初めての場合は「簡単」がおすすめです。

オンライン対戦は現在準備中です。今は「CPU対戦」でお楽しみください。

### Windows版をローカルで実行する場合

1. [リリースページ](https://github.com/makinakatsuta/stt/releases/latest) から最新の `stt.exe` をダウンロードします。
2. ダウンロードした `stt.exe` を実行します（ゲームに必要な画面・音源データなどはすべてこのファイルに含まれています）。
3. ブラウザを開き `http://localhost:8080` にアクセスします。（※黒い画面に別のURLが表示された場合は、そちらを使用してください）
4. 「ゲームを開始する」を選択し、「CPU対戦」から難易度を選んでゲームを開始します。

## 🕹️ 基本操作

どの難易度でも、ラケットの移動と返球は**プレイヤー自身が操作**します。自動追尾はありません。球の音が近づいたら、ラケットの横位置を合わせて返球してください。

| 操作 | パソコン | スマートフォン・タブレット |
|---|---|---|
| **ラケットの移動** | 左右矢印キー | 端末を左右に傾ける |
| **サーブ / 返球** | Spaceキー | 画面をタップ |
| **試合の中断** | Escapeキー | 中断ボタンをタップ |

- **スクリーンリーダーをご利用の場合:** 
  プレイ画面の「サーブ・返球」ボタンを実行（Enter/Space または ダブルタップ）することでも操作可能です。このボタンを使う場合、サーブ時の長押しは不要です。（従来のコート領域での操作や、Spaceキーによる操作も引き続き可能です）
  ボタン名はプレイ中も変わりません。操作方法はヘルプ画面・中断メニューで確認できます。プレイ中のスコア・サーブ権・審判コールの画面表示と補助説明は読み取り対象から外し、必要なゲーム案内を専用の通知領域から読み上げます。試合終了後の結果・操作ボタンは読み取り対象に戻ります。
- **中断メニュー:** 
  試合を一時停止し、再開、操作方法の確認、難易度選択（TOP）に戻ることができます。TOPに戻って試合を終了すると進行状況はリセットされます。

## 🎯 3つの難易度

| 難易度 | 特徴 |
|---|---|
| **簡単（Easy）** | 球がゆっくりで、返球しやすい練習向けです。初めて遊ぶ方におすすめです。 |
| **ノーマル（Normal）** | 球の速さや飛んでくる方向に変化があります。操作に慣れたら挑戦してみてください。 |
| **ハード（Hard）** | Normalより速く、左右への配球も厳しい上級者向けです。ラリーを続けたり良いコースへ返したりすることで得点のチャンスが生まれます。 |

得点後は、判定・得点者・現在のスコアを音声で案内します。

## ⚙️ 表示・音声・アクセシビリティ設定

起動画面で、環境や見え方に合わせた設定が可能です。設定はブラウザに保存されます。

### 画面と音声の設定
- **読み上げ方式**：「ゲーム内蔵音声（初期設定）」または「スクリーンリーダー」から選択できます。スクリーンリーダー方式を選ぶと内蔵の音声案内を停止し、専用の通知領域のみを更新します。（※球音・打球音はどちらの方式でも再生されます）
- **配色**：標準 / 黒背景・白文字 / 白背景・黒文字（白黒反転） / 黒背景・黄色文字
- **文字サイズ**：100% / 125% / 150% / 200%（メニュー・得点・案内に適用）
- **音声の速さ**：0.5〜2.0倍

### 対象環境・動作確認について
- Windows 11のChrome・Edge・Firefox、Androidの対応ブラウザ、iPhone・iPadのSafariなどを対象としています。
- 全盲の利用者による、WindowsのFirefox・Chrome・Edge、およびAndroidのChrome、iPhoneのSafariなどでのプレイ実績・動作確認報告があります。

### スマートフォンで遊ぶ

#### ブラウザ版

スマートフォンのブラウザから[公開URL](https://soundtabletennis.com/)を直接開けば遊べます。傾き操作のセンサー利用を求められた場合は許可してください。スクリーンリーダーでは「サーブ・返球」ボタンを選び、ダブルタップで実行できます。

#### ローカルWindows版

パソコンで起動した `stt.exe` と同じWi-Fiにスマホを接続し、起動時に表示されたLAN内のURLを開くことでプレイ可能です。
- 端末の傾きで操作する場合は、設定で「スマホを左右に傾けてラケットを操作する」をオンにし、センサーの利用を許可してください。
- センサーが利用できない環境（HTTP接続による制限など）の場合は、外付けキーボードを使用するか、HTTPS化の手順を踏む必要があります。

## 🏓 試合のルール

現実のサウンドテーブルテニスのルールを参考に、遊びやすく調整しています。

- **勝利条件**: 1ゲーム11点先取で、先に2ゲーム取った方の勝ち（最大3ゲームマッチ）。
- **デュース**: 10対10になった後は、2点差がつくまで続きます。
- **サーブ権**: 2ポイントごとに交替（10対10以降は1ポイントごと）。
- **促進ルール**: 1ゲームが長引いた場合、レシーバーが7回返球に成功するとレシーバーの得点になる特別ルールが発動することがあります。

## 💡 困ったとき

- **音が出ない**
  開始ボタンを正しく押したか、端末やブラウザの音量設定、イヤホンの接続を確認してください。解決しない場合はページを再読み込みしてください。
- **スマートフォンでラケットが動かない**
  センサー設定・許可がオンになっているか確認してください。画面を上に向けて持ち、動かしたい側を下げてください。水平に戻すと止まります。
- **ページが開かない**
  ブラウザ版のリンクとインターネット接続を確認してください。Windows版の場合は、`stt.exe` が起動しているか、URLやポート番号が正しいかも確認してください。
- **アップデート（更新）が反映されない**
  ブラウザ版ではページを再読み込みしてください。Windows版では最新版の `stt.exe` に置き換えて起動し、ブラウザのキャッシュをクリア（再読み込み）してください。画面下のバージョン表記、または `stt.exe --version` で現在のバージョンを確認できます。
